Scribe : Build a clean, minimal Notion-like note-taking app where users can create, edit, and organize notes into pages — with autosave, markdown-like formatting, and a modern UI.

Tech Stack:

⚙️ Frontend
• Framework: Nextjs
• Language: TypeScript
• Styling: Tailwind CSS
• State Managemnet: React hooks
• Rich Text Editor: Tip Tap or Lexial

🧠 Backend
• Databse: PostgreSQL
• ORM: Prisma
• Authentication: NextAuth
• API Layer: Nextjs API Routes or Route Handlers
• Validation Zod

☁️ Deployment & DevOps
• Frontend & API: Vercel
• Database: Neon.tech
• Environment Variables: Vercel Dashboard
